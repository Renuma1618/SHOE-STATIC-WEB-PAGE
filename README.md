**👟 Shoe Static Web Page**
This project is a static website created using HTML and CSS to showcase a shoe product. The layout is clean and modern, featuring an image of the shoe, product name, price, size options, and color selections. The design mimics a simple product landing page for an e-commerce site.

**✅ What I Did**
Built a two-column layout using Flexbox (image on the left, details on the right)

Added product information: title, price (with discount), sizes, and color options

Styled UI elements like  text, and color circles using CSS

Used a background image for better visual appearance

Positioned and sized the shoe image for focus and balance

**🛠️ Technologies Used**
HTML5 for structure

CSS3 for layout and styling

📚 What I Learned**
**How to structure a product layout using only HTML & CSS

Flexbox for aligning items

Styling interactive elements without JavaScript
